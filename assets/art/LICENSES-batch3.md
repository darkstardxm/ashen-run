# LICENSES / provenance: Ashen Run art batch 3

Every file in batch 3 is listed. There are no third-party assets, source images or references.
- Everything is original work made for Dexter Massoletti. It is either procedural (Blender/bpy, numpy and Pillow scripts in `models/src/`) or derived from the batch 1 Grok Imagine floor textures.
- Batch 1 and batch 2 provenance still applies to the files batch 3 builds on. See `../batch1/LICENSES.md` and `../batch2/LICENSES.md`.
- Tools:
  - Blender 4.2.9 (GPL; output assets are not covered by the GPL).
  - glTF Transform CLI 4.5 (MIT).
  - three.js r170 (MIT) and puppeteer-core (Apache-2.0), used only for the render harness and load test; not shipped.
